## Build on shared tokens

Strata provides UI kits built on semantic CSS variables such as `--primary`,
`--space-3`, and `--radius`. Products share component styles and behaviors while
keeping their own themes and domain components.

<CardGrid stagger>
  <Card title="Theme with tokens" icon="setting">
    Override semantic colors and their foreground pairs in the product theme.
    Components read those tokens for fills, text, and interaction states.
  </Card>
  <Card title="Scheme and density" icon="puzzle">
    Dark Knight and Désert Dunes each work with comfortable or compact density.
    Both settings use token overrides.
  </Card>
  <Card title="Use any framework" icon="document">
    Classes style the markup. JavaScript attaches through `data-*` hooks on the
    rendered DOM. Call `QZ.init(root)` after inserting new behavior markup.
  </Card>
  <Card title="Keyboard support" icon="approve-check">
    Dialogs manage focus, tabs support arrow keys, and accordions use native
    details elements. The accessibility guide documents each interaction.
  </Card>
</CardGrid>

## Install

```bash
npm install @qazana/strata
```

For plain HTML, copy the package's `tokens`, `kits`, `fonts`, and `js`
directories to your public `/vendor/strata/` directory. Preserve their relative
paths, then load them with public URLs:

```html
<link rel="stylesheet" href="/vendor/strata/tokens/qazana.tokens.css" />
<link rel="stylesheet" href="/vendor/strata/kits/app.css" />
<script type="module" src="/vendor/strata/js/qazana.js"></script>

<button type="button" class="btn btn-primary">Save</button>
```

See [Install](/getting-started/install/) for bundler imports and kit choices.
These docs follow the repository; check the [changelog](/reference/changelog/)
for published versions and unreleased additions.
