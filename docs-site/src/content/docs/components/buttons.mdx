## Variants

`.btn` plus one variant class:

| Class | Use |
| --- | --- |
| `.btn-primary` | primary action (filled brand) |
| `.btn-secondary` | secondary filled |
| `.btn-outline` | bordered, transparent fill |
| `.btn-ghost` | transparent, no border until hover |
| `.btn-danger` | destructive action |
| `.btn-link` | looks like a link |

## Sizes, states, groups

- `.btn-sm` · `.btn-icon` (icon-only)
- States: `.is-loading` (with `<span class="spin sm">`), `.is-success`, `.is-disabled`
- Groups: `.btn-group` (joined) · `.segmented` (single-select) · `.toggle-group` (multi, JS toggles `.on`)

All padding/size flows through the density tokens, so buttons shrink in
[compact mode](/foundations/density/).

Use native `disabled` to prevent button activation. `.is-disabled` supplies
visual styling and does not replace native semantics.

## Standalone buttons (experimental)

The **Unreleased** `@qazana/strata/button` entry uses `.qz-button` and a single
variant such as `.qz-button-primary`. It loads button-local tokens with no page
reset, font files, or JavaScript. It is experimental and may change in a minor
release.

```css
@import '@qazana/strata/button';
```

```html
<button class="qz-button qz-button-primary" data-qz-theme="light">Save</button>
```

Set `data-qz-theme` on each button; unset follows the OS. The host owns the
matching background. Ancestor `data-theme` and `data-density` do not affect this
entry. See the [full reference](https://github.com/Qazana/strata/blob/master/docs/button.md)
for supported variants, token overrides, and disabled semantics.
