## Loading

`.spin` (`.sm` / `.lg`) · progress bar · indeterminate `.prog-indet` · `.radial`
· skeletons `.skel` (`.skel-line`) · section `.loading-block` · activity log
`.log` (`.t` / `.ok` / `.warn` / `.cur` / `.blink`).

## Step tracker

`.steps` > `.step` (`.done` / `.active`) + `.sdot`, separated by `.sline`. A
`.step.done` tints the following `.sline`.

## Upload list

`.upload-list` > `.upload-row` (`.done`) with `.uicon` / `.uinfo` (`.uname` /
`.umeta` / `.ubar` > `i`) + `.urm` remove button.
