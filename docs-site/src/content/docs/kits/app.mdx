The **App kit** (`@qazana/strata/app`) provides forms, tables, overlays, and admin
layouts. Load the behavior script for keyboard interaction and ARIA state on
the documented `data-*` hooks. Authors supply labels and the required markup.

## What's inside

Buttons & variants · full form coverage (inputs, combobox, stepper, tags, OTP,
upload, validation) · badges/tags/status · cards · charts · stats · data table
(sort/select/filter/expand/sticky) · tree · overlays (modal, drawer, popover,
popconfirm, command palette, tooltip, menu) · loading & progress · steps · upload
list · toasts & banners. See the [Components](/components/buttons/)
section for per-area detail and APIs.
