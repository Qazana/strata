The **Email kit** (`@qazana/strata/email/*`) provides
table-based, client-safe email templates that still draw their colours and type
from the token foundation.

:::note
Email clients are unforgiving — these templates use table layout and inlined-safe
patterns rather than the `data-*` behaviours or `@layer` cascade used elsewhere.
The shared element is the **palette and type**, not the interactive JS.
:::
