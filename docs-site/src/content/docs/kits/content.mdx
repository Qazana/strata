The **Content kit** (`@qazana/strata/content`) handles editorial
surfaces: blog listings, article layouts, `.prose` typography, callouts, and a
docs layout with a sticky table-of-contents scrollspy.

## Article with TOC

The `.doc-layout` puts prose beside a sticky `.toc` ( `[data-toc]` ) whose links
highlight the section in view via IntersectionObserver:

## Variants

`blog`, `blog-medium`, `article`, `article-plain` (no hero image), and
`article-media` (with embedded video/audio). The prose styles (`.prose`,
`.callout`, `blockquote`, code blocks) compose with the Site kit header/footer.
