Foundation

FAQ

Questions, answered

Do I need a build step?

No. Link the tokens and a kit stylesheet, add the script, and you're done — it works in any framework via the rendered DOM.

How do themes work?

Set data-theme="desert-dunes" or "dark" on the html element, or leave it unset to follow the OS. Tokens set color-scheme for you.

Can I use my own brand colours?

Yes — override the brand tokens in a small theme file. One override re-tints everything because components reference tokens, never raw values.

Which kits are available?

The App and Site kits ship today; Content, Auth and Email kits are on the roadmap. All share the same foundation.
